# 🎮 Tic-Tac-Toe Web Game

Interactive tic-tac-toe game with AI opponent built with HTML, CSS, and JavaScript.

-> Features
- Human vs Human mode
- AI opponent with smart algorithm
- Modern UI design
- Score tracking

-> How to Play
1. Open index.html in browser
2. Choose game mode
3. Click cells to make moves
4. Get 3 in a row to win!

-> Technologies Used
- HTML5
- CSS3
- JavaScript
- Minimax Algorithm
